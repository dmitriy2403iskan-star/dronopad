# Outkit — Offline Blackout Kit

Скачивание видео с YouTube на телефон: канал / ссылка / поиск, нужное количество,
видео или аудио, очередь, фоновая работа (foreground-сервис), ожидание интернета и докачка.

## Как получить APK
1. Залейте все файлы в репозиторий GitHub (с папкой `.github`).
2. Вкладка **Actions** → дождитесь зелёной галочки сборки (10–25 мин).
3. Откройте сборку → **Artifacts** → `YTLoader-apk` → скачайте и установите APK.

## Важно
- Без ffmpeg доступны только готовые потоки (видео обычно до 360p), аудио — m4a.
- Чтобы фон не убивался: Настройки → Приложения → Outkit → Батарея → «Без ограничений».
- Если YouTube перестал отдавать видео — пересоберите (Actions → Run workflow): подтянется свежий yt-dlp.
- Только для личного использования, соблюдайте условия YouTube и авторские права.

## Первый модуль: YouTube Downloader

Первый экран Outkit — загрузчик видео и аудио с YouTube. Он использует существующую очередь,
фоновую службу, ожидание соединения и докачку.

### Передача на iPhone

Следующий модуль проекта может добавить локальную передачу файлов по Wi-Fi:
Outkit поднимает локальную страницу с файлами и показывает QR-код, который можно открыть
на iPhone. Интернет для самой передачи не требуется; устройства должны находиться в одной
локальной сети.

### Офлайн-модули Outkit

Архитектура рассчитана на дальнейшее добавление фонарика, заметок, таймера, игр,
офлайн-справочника и других функций для работы во время отключений электричества.
